# 每日任务 DTO 和 VO 生成计划

## 目标
根据 `DailyTaskEntity` 实体结构，生成完整的 DTO 和 VO 类，支持每日任务的增删改查操作。

## 实体字段分析

| 字段 | 类型 | 说明 | 创建必填 | 更新可改 |
|------|------|------|----------|----------|
| familyId | Long | 家庭ID | 自动获取 | ❌ |
| userId | Long | 用户ID | ✅ | ❌ |
| templateId | Long | 模板ID（可选） | ❌ | ❌ |
| taskDate | LocalDate | 任务日期 | ✅ | ❌ |
| name | String | 任务名称 | ✅ | ✅ |
| category | String | 分类 | ✅ | ❌ |
| icon | String | 图标 | ❌ | ✅ |
| points | Integer | 积分值 | ✅ | ✅ |
| deadlineTime | LocalTime | 截止时间 | ❌ | ✅ |
| sortOrder | Integer | 排序 | ❌ | ✅ |
| status | String | 状态 | ✅ | ✅ |
| isTemp | Integer | 是否临时任务 | ❌ | ❌ |
| reminded | Integer | 是否已提醒 | ❌ | ❌ |

## 实施步骤

### 1. 创建 `DailyTaskDTO.java`
路径: `src/main/java/com/family/hub/module/task/dto/DailyTaskDTO.java`

包含内容：
- 创建请求参数：name, category, points, taskDate, userId 必填校验
- 可选参数：templateId, icon, deadlineTime, sortOrder, isTemp
- 验证注解：`@NotBlank`, `@NotNull`, `@Min`, `@Pattern`
- Lombok 注解：`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`

### 2. 创建 `DailyTaskUpdateDTO.java`
路径: `src/main/java/com/family/hub/module/task/dto/DailyTaskUpdateDTO.java`

包含内容：
- 仅包含可更新字段：name, icon, points, deadlineTime, sortOrder, status
- 验证注解：适当校验

### 3. 更新 `DailyTaskVO.java`
路径: `src/main/java/com/family/hub/module/task/vo/DailyTaskVO.java`

补充字段：
- familyId（家庭ID）
- reminded（是否已提醒）
- createdAt, updatedAt（时间戳，可选）

## 代码模板

### DailyTaskDTO
```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class DailyTaskDTO {
    @NotNull(message = "用户ID不能为空")
    private Long userId;

    private Long templateId;  // 可选，从模板创建

    @NotNull(message = "任务日期不能为空")
    private LocalDate taskDate;

    @NotBlank(message = "任务名称不能为空")
    @Size(max = 64, message = "任务名称最长64位")
    private String name;

    @NotBlank(message = "分类不能为空")
    @Pattern(regexp = "STUDY|SPORT|CHORE|HOBBY|OTHER", message = "分类只能是 STUDY/SPORT/CHORE/HOBBY/OTHER")
    private String category;

    @Size(max = 32, message = "图标标识最长32位")
    private String icon;

    @NotNull(message = "积分不能为空")
    @Min(value = 0, message = "积分不能为负数")
    private Integer points;

    private LocalTime deadlineTime;
    private Integer sortOrder;
    private Integer isTemp;  // 0=模板生成, 1=临时任务
}
```

### DailyTaskUpdateDTO
```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class DailyTaskUpdateDTO {
    @Size(max = 64, message = "任务名称最长64位")
    private String name;

    @Size(max = 32, message = "图标标识最长32位")
    private String icon;

    @Min(value = 0, message = "积分不能为负数")
    private Integer points;

    private LocalTime deadlineTime;
    private Integer sortOrder;

    @Pattern(regexp = "PENDING|DONE|EXPIRED|SKIPPED", message = "状态只能是 PENDING/DONE/EXPIRED/SKIPPED")
    private String status;
}
```

### DailyTaskVO（更新）
```java
@Data
@Builder
public class DailyTaskVO {
    private Long id;
    private Long familyId;
    private Long userId;
    private Long templateId;
    private LocalDate taskDate;
    private String name;
    private String category;
    private String icon;
    private Integer points;
    private LocalTime deadlineTime;
    private Integer sortOrder;
    private String status;
    private Integer isTemp;
    private Integer reminded;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}
```

## 状态枚举说明
- `PENDING`: 待完成
- `DONE`: 已完成
- `EXPIRED`: 已过期
- `SKIPPED`: 已跳过

## 分类枚举说明
- `STUDY`: 学习
- `SPORT`: 运动
- `CHORE`:家务
- `HOBBY`: 兴趣
- `OTHER`: 其他
